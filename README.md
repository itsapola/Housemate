# housemate.

Design for shared spaces. Modern furniture for cats, with other pets to follow.

Concept brand site for Collection 01: The Cocoon, The Column, and The System.

## Structure

- `index.html` — the whole site (HTML, CSS, JS in one file). Views route on the URL hash: `#home`, `#shop`, `#the-cocoon`, `#the-column`, `#the-system`, `#about`, `#journal`.
- `img/` — WebP product cutouts, editorial photography, logo, and fabric swatches.

## Run locally

Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Deploy

Static site, no build step. Deploys as-is to Vercel, Netlify, or GitHub Pages.

## Notes

Prices, dimensions, and material claims are placeholders for the concept.
